## Project

Dual-language library (Go + TypeScript) for extracting text content and metadata from unstructured file formats (Office, ODF, PDF, images, audio, CAD). Commercial-friendly, minimal dependencies, low memory footprint. TypeScript port has proven output parity via golden file tests. Optional OCR text extraction from images via Tesseract. GeoTIFF metadata support.
